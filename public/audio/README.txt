TINDERBOX SOUND FILES

Put one audio file per card in this folder. The name must start with the card number.
Any of these formats work: .mp3 .wav .m4a .aac .ogg .flac
The words after the number are only for you; they are ignored.

A card with no file still works: the sound computer speaks its poem aloud instead
(or plays a soft chime if that option is switched off), so you can rehearse before every file exists.

You can also skip this folder: drag the files straight onto the sound page (press h), and they stay on that computer.
